# ValhallaApp v2.0.0 发布说明

- 版本：`2.0.0`（`versionCode 20`）
- 发布日期：2026-11-05
- 定位：面向 BLE/IoT 设备的 Kotlin Multiplatform 调试与管理客户端

## 1. 版本要点

| 方向 | 内容 |
| --- | --- |
| 设备接入 | BLE 扫描/去重/排序、连接、鉴权（界面默认令牌；HMAC-SHA256 签名挑战在控制器层可用）、设备信息、电量与固件版本 |
| 配置 | 按固件版本与型号做能力协商，只展示可编辑项；本地校验后才下发 |
| OTA | 固件解析与签名段识别、本地预检、分片传输、同偏移重传、进度/速率、断点续传与手动清除 |
| 稳定性 | 统一异常边界（用户取消/协程取消/超时/失败四类）、状态机终态收敛、连接池资源回收、报文日志并发安全 |
| 隐私 | 报文日志脱敏默认开启且无关闭入口；日志仅存内存；未声明 `INTERNET`，无任何网络上传 |
| 产品化 | 中英双语、跟随系统/手动主题、设备档案与 OTA 历史、关于/帮助/隐私页 |
| 日志与导出 | 500 条环形报文日志、命令/错误/时间/关键字筛选、TEXT/JSON/CSV 流式导出与系统分享 |
| 交付工程 | 版本单一来源、`verifyVersionConsistency`/`verifyReleaseArtifact`、四档 CI、本机工具链记录 |

历史版本演进见 [CHANGELOG.md](../../CHANGELOG.md)，架构与协议细节见 [文档索引](../README.md)。

## 2. 能力边界

**已实现并含自动化验证**

- 协议帧编解码、CRC16-CCITT、流式分帧（粘包/拆包）；
- 指令调度：seq 配对、超时重试、通知广播、GATT 写入串行化；
- 完整 OTA 链路（含续传接受/下调/拒绝三分支与旧设备回退），由 `protocol-testkit` 设备模拟器在 JVM 上端到端覆盖；
- 权限/可用状态状态机、断连原因映射、自动重连退避（1/2/4/8/16 秒，最多 5 次）；
- 配置能力协商、报文日志筛选/导出/脱敏、设备档案与保留策略；
- 版本号同源校验与 release 产物校验。

**实现但未接入产品界面 / 需自行配置**

- HMAC-SHA256 签名鉴权：`DeviceDetailController.authenticateWithSignature` 与签名器已实现并有测试，
  但界面默认只走令牌鉴权；生产密钥需自行注入；
- 固件签名段解析与预检：默认 `WARN` 策略且未注入验签器，签名固件会告警而非强制拒绝；
  `REQUIRE` 与真实验签器需自行装配。

**明确不包含**

- 云端账号、远程下发、设备影子、崩溃埋点或遥测上报；
- 生产级固件验签：ECDSA-P256 只定义了算法编号与接口，仓库内完整验签实现为 HMAC-SHA256 测试密钥；
- 固件侧（设备端）实现：本仓库只提供协议字典与测试桩；
- 应用商店上架材料、企业签名、正式分发渠道配置。

## 3. 已知限制

1. **Release 产物未签名**：本轮与 CI 产出的均为 `composeApp-release-unsigned.apk`，不能直接安装为正式包，也不能覆盖已安装的签名版本。
2. **真机行为未验证**：权限弹窗、系统设置跳转、真实 BLE 连接/断连时序、真机 OTA、KeyStore/Keychain、系统分享面板均未在真机上验收。
3. **固件回传自由文本未脱敏**：`GET_DEVICE_INFO` 的结构化字段（厂商/型号/固件版本）原样保留，若设备在这些字段中写入敏感信息，当前不做处理。
4. **单链路单调度器**：一条 BLE 链路的 `incoming` 是冷流，约定只由一个 `ConcurrentCommandDispatcher` 收集；同一设备重复创建调度器会导致上行分流。
5. **配置命令表是仓库内置字典**：真实产品型号的命令/键位需按 [protocol.md](../protocol.md) 接入，未接入的键不会展示。
6. **iOS 交付形态**：仅验证 `linkDebugFrameworkIosSimulatorArm64` 与 Xcode Debug 构建链路，未提供签名 `.ipa`、未做 Archive/TestFlight。
7. **无长稳数据**：压力测试为固定种子/短时用例，小时级运行与弱信号环境表现未测量。

## 4. 安装前提

### Android

- 系统：Android 8.0（API 26）及以上；`targetSdk 36`、`compileSdk 36`；
- 硬件：支持 Bluetooth Low Energy；
- 权限：
  - Android 12+（API 31+）：`BLUETOOTH_SCAN`、`BLUETOOTH_CONNECT`（「附近的设备」）；
  - Android 11 及以下：`ACCESS_FINE_LOCATION`（定位），以及安装时授予的 `BLUETOOTH`/`BLUETOOTH_ADMIN`；
  - 首次进入扫描页按状态机申请，永久拒绝后需到系统设置开启。
- 安装 unsigned APK（仅本地验证）：

```bash
adb install -r composeApp/build/outputs/apk/release/composeApp-release-unsigned.apk
# 部分系统/ROM 会拒绝未签名包；这是预期行为，不代表应用缺陷
```

### iOS

- 系统：iOS 15.0 及以上（`IPHONEOS_DEPLOYMENT_TARGET = 15.0`）；
- 工具链：macOS + Xcode；Kotlin/Native 链接由 Xcode 构建阶段调用 Gradle；
- 权限：`NSBluetoothAlwaysUsageDescription`（已写入 `Info.plist`），并声明 `bluetooth-central` 后台模式；
- 本仓库不提供 `.ipa`，需在 Xcode 中选择自己的开发团队签名后运行到真机。

### Release 签名（可选，需要自备 keystore）

仓库不包含任何 keystore，也不会生成假签名产物。配置通道二选一：

```bash
# 方式一：环境变量（四项必须同时提供）
export VALHALLA_KEYSTORE_PATH=/absolute/path/valhalla-release.keystore
export VALHALLA_KEYSTORE_PASSWORD='***'
export VALHALLA_KEY_ALIAS=valhalla
export VALHALLA_KEY_PASSWORD='***'
./gradlew :composeApp:assembleRelease :composeApp:verifyReleaseArtifact
```

```properties
# 方式二：项目根目录 keystore.properties（已 gitignore，不要提交）
storeFile=/absolute/path/valhalla-release.keystore
storePassword=***
keyAlias=valhalla
keyPassword=***
```

- 四项齐全：产出签名 APK，`verifyReleaseArtifact` 会拒绝 unsigned 产物；
- 只配置一部分：Gradle 直接失败并列出缺失项；
- 全部缺失：允许构建，产物为 unsigned，仅用于本地验证。

## 5. 真机验收清单

以下项目**本轮均未验证**，交付验收时需逐项执行并记录设备型号/系统版本：

- [ ] Android 12+ 首次进入扫描页弹出「附近的设备」权限，允许后可扫描并连接；
- [ ] Android 11 及以下弹出定位权限，拒绝后可再次申请，勾选「不再询问」后引导到系统设置；
- [ ] iOS 首次使用弹出蓝牙授权，拒绝后显示「去系统设置」；
- [ ] 扫描 12 秒无设备显示超时文案，与无权限/蓝牙关闭文案不同；
- [ ] 连接成功后读取设备信息、固件版本、电量与充电状态；
- [ ] 配置项按固件/型号隐藏不支持项，保存后重启应用仍能读回；
- [ ] 正常 OTA 全流程完成，设备重启后版本号更新；
- [ ] 升级中断连后重连可续传，断点偏移与设备确认值一致；
- [ ] 升级中主动中止后断点保留，清除断点后从 0 开始；
- [ ] 设备断电/超距后按 1/2/4/8/16 秒自动重连，5 次后停止并可手动重试；
- [ ] 报文日志在真机长时间 OTA 下保持 500 条上限，导出文件可被系统应用打开；
- [ ] 授权前后切换语言/深色模式，界面与错误文案同步刷新；
- [ ] 卸载重装后 KeyStore/Keychain 令牌行为符合 [security.md](../security.md) 描述；
- [ ] 已签名 release APK 在真机覆盖安装、升级安装均成功。
