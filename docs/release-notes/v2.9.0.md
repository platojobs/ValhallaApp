# v2.9.0 - 批量、队列与可复用固件库

- 版本：`2.9.0`（`versionCode 29`）
- 基线：v2.8.0（远端 `2c3e35b`）
- 主题：从「一台一台手动点」变成「批量、队列、可复用」

## 批量操作（多设备）

- 入口来自「已连接设备」列表：批量体检、批量应用某个配置预设。
- 严格串行执行，避免 GATT 并发冲突；界面逐台显示状态与当前步骤，可取消剩余任务。
- 单台失败（断链、拒绝、超时、执行异常）只标记该台并继续下一台，不整体中止。
- 连接中途掉线的设备从队列移除并标注原因；不做自动重连后续跑。
- 结束汇总：成功/跳过/失败/取消/移除台数与原因，可按设备展开；汇总可复制，也可走既有
  保存通道落盘，文本经既有脱敏与 deviceId 哈希处理。
- 执行期间通过 `DeviceOperationLocks` 锁定参与设备的配置、参数、OTA 与快捷操作；未参与
  设备不受影响。

## 本地固件库

- 可导入多个固件包：解析头部元数据（型号白名单、版本、渠道、大小、CRC32），按 deviceId
  无关的全局库管理；支持列表、按型号/版本筛选、排序、删除与别名重命名。
- 同一内容（CRC32 + 总长 + 版本）重复导入归并为同一包；损坏包导入时报具体错误码并拒绝入库。
- OTA「选择固件」增加「从固件库选择」，按当前设备型号与版本给出「适用/不适用」及原因，
  复用既有预检判定；支持「一键选中最新的适用包」。
- 条目只存元数据与文件引用，不复制大文件进偏好存储；引用失效（文件被删/权限丢失）时标记
  为不可用，并给出重新选择文件的入口。
- 从固件库使用固件仍走完整预检，不跳过 CRC 与签名校验。

## OTA 队列

- 可将多台已连接设备 + 固件库包排成队列，逐台串行升级；队列表显示每台的阶段与进度。
- 支持暂停队列（当前设备完成当前分片后停在安全点）、取消当前（复用既有 Abort 语义）、
  跳过失败设备、移除排队项。
- 升级失败的设备保留其断点，队列继续下一台；队列结束给出成功/失败/跳过汇总。断点复用
  沿用既有四重门控，不放松。
- 队列状态只在内存与必要断点中保存，不提供后台续跑；退出 App 会中断队列，界面明确提示。

## 测试与边界

- 新增测试：批量串行与单台失败继续、批量锁定范围、取消剩余、汇总统计；固件库去重/损坏
  拒绝/引用失效/适用性判定/最新适用包；队列状态机（暂停安全点、取消当前、跳过失败、汇总）、
  失败设备断点保留、队列不跨进程续跑。
- JVM 测试基线 648 不回归（本期实际 679），版本一致性测试同步到 `2.9.0` / `29`。
- 不支持后台批量或队列续跑；任何绕过预检或签名校验的实现均视为缺陷。
