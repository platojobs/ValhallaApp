# ValhallaApp v2.2.0 发布说明

- 版本：`2.2.0`（`versionCode 22`）
- 发布日期：2026-11-05
- 定位：跨端运行时验签与构建期公钥注入

## 1. 版本要点

| 方向 | 内容 |
| --- | --- |
| 跨端验签 | 同一批 OpenSSL ECDSA-P256 向量在 JVM、Android instrumented（真实 Android 运行时）与 iOS 模拟器（`Security.framework`）真实执行 |
| 公钥注入 | 构建期从 `VALHALLA_FIRMWARE_PUBKEY` / `valhalla.firmwarePublicKey` 注入，生成 Android assets、JVM classpath、iOS 资源与编译期常量 |
| 策略一致性 | 未注入保持 `WARN`；注入非法公钥失败关闭；关于页展示「已配置 / 未配置」 |
| 异常桥接 | Android/JVM `Thread.setDefaultUncaughtExceptionHandler`、iOS `NSSetUncaughtExceptionHandler` 接入 `ErrorReporter`，仅本地记录 + 脱敏投递 |
| 性能护栏 | `SensitiveTextRedaction` 1 MB 文本耗时上限测试（本机 208ms） |
| 版本 | `2.2.0` / `versionCode 22`，`verifyVersionConsistency` 通过 |

本次变更见 [CHANGELOG.md](../../CHANGELOG.md) 的 v2.2.0 分节；历史发布说明见 [v2.0.0](v2.0.0.md)。

## 2. 公钥注入

优先级：

1. 环境变量 `VALHALLA_FIRMWARE_PUBKEY`
2. Gradle property `valhalla.firmwarePublicKey`
3. 缺省（不注入，预检 `WARN`）

示例：

```bash
export VALHALLA_FIRMWARE_PUBKEY="$(cat firmware-public.pem)"
./gradlew :composeApp:assembleRelease
```

或：

```bash
./gradlew :composeApp:assembleRelease \
  -Pvalhalla.firmwarePublicKey="$(cat firmware-public.pem)"
```

CI 中把公钥 PEM 放入仓库 secret（例如 `FIRMWARE_PUBLIC_KEY`），构建步骤设置
`VALHALLA_FIRMWARE_PUBKEY: ${{ secrets.FIRMWARE_PUBLIC_KEY }}` 即可。仓库**不包含**任何真实
公钥或私钥。

产物：

| 平台 | 位置 |
| --- | --- |
| Android | `feature/build/generated/firmware/resources/firmware/signing-key.pem` → APK assets |
| JVM | 同一资源目录 → classpath `firmware/signing-key.pem` |
| iOS | 同一资源目录 + 生成常量 `BuildInjectedFirmwareKey.PEM`（静态 framework 不打包资源时兜底） |

## 3. 跨端运行时验证

- 共享向量对象 `com.valhalla.core.security.testdata.EcdsaTestVectors`（commonMain，仅公开测试公钥）；
- Android：`core/src/androidInstrumentedTest/.../EcdsaP256AndroidRuntimeTest.kt`，7 个测试方法，真实 `java.security.Signature("NONEwithECDSA")`；
- iOS：`core/src/iosSimulatorArm64Test/.../EcdsaP256IosRuntimeTest.kt`，6 个测试方法，真实 `SecKeyVerifySignature(...DigestX962SHA256)`；
- CI：`android-instrumented`（ubuntu + KVM + AVD API 30）与 `ios-runtime-tests`（macos-14）均为失败即红，未使用 `continue-on-error`。

## 4. 已知限制与未验证项

- iOS `NSSetUncaughtExceptionHandler` 只捕获 Objective-C 异常；Kotlin/Native 未捕获异常不经过该回调；
- 未捕获异常桥接没有真实崩溃演练；未在真机上验证崩溃进程退出行为；
- 公钥注入的生产密钥管理（KMS/Hardware Security Module）不在本仓库；
- 真机权限弹窗、BLE/OTA、Keystore/Keychain、系统分享、TalkBack/VoiceOver、字体缩放与横屏排版仍未验证；
- 仓库不含 keystore，release 产物仍为 unsigned。
