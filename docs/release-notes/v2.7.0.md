## 2. 关键规则

### 预设差异与部分失败

- 差异三态：`WILL_CHANGE`（当前值 → 目标值）、`ALREADY_TARGET`（已是目标值，不下发）、
  `UNSUPPORTED`（未知键/只读/设备能力不满足/值非法，跳过并说明原因）；
- 确认后逐键写入 `SET_CONFIG`；单键失败继续后续键，结果列出成功、已是目标、跳过与失败，
  设备拒绝附错误码 `0x..`；链路/超时失败同样只影响当前键，不整包回滚；
- 预设存于平台偏好存储，损坏或版本不符回退为空列表。

### 自动化触发边界

- 只在 App 前台且「连接成功（含自动重连）」或「OTA 成功」回调发生时执行；
- 没有后台唤起、没有 WorkManager/后台任务、没有设备侧规则；
- 单条规则失败写入 `AUTOMATION` 事件并继续后续规则；链路断开时该规则记为失败并跳过；
- 「应用预设」必须绑定一个仍存在的预设，预设被删除时该条执行失败并记录原因。

### 统计口径

- 连接次数：事件时间线中成功的 `CONNECTION` 事件；平均时长只统计「连接成功 → 断开」完整会话，
  未结束会话不计入；
- OTA：设备档案历史记录，按结束时间筛选；成功率与平均耗时只用真实记录；
- 配置/参数写入：成功 `CONFIG_CHANGE` / `PARAM_CHANGE` 事件；体检：`HEALTH` 事件条数；
- 无数据维度显示「暂无数据」，不做模拟或估算；页面声明「仅本机统计，不上传」。

### 备份字段白名单

导出仅包含：语言、主题、重连策略（次数与退避上限）、日志容量、导出默认值（条数/大小/HEX）、
预设、自动化规则、引导标记，以及 `schema` / `schemaVersion` / `appVersion` 元信息。

明确排除：令牌、密钥、凭证、设备档案、日志、断点。

导入先校验 `schema` 与 `schemaVersion`；缺失或非法字段回退默认并逐条提示，非法预设/规则条目
跳过；导入前展示将被覆盖的项。恢复出厂设置清空偏好与预设，二次确认，不删除设备档案与令牌。

## 3. 未验证项

- 预设与自动化规则在真实设备能力差异下的完整表现（型号/固件能力矩阵）未逐一验证；
- 真实设备上 OTA 成功回调触发自动化规则的时序未验证；
- 备份 JSON 在跨版本导入（未来 schema 变更）时的兼容策略未验证；
- 使用统计在长期真实数据（数百条事件与多设备）下的界面性能未验证。
