- 版本：`2.6.0`（`versionCode 26`）
- 发布日期：2026-11-05
- 定位：以用户可见功能为主——设备体检、固件升级向导、设备仪表盘

历史版本演进见 [CHANGELOG.md](../../CHANGELOG.md)，架构与协议细节见 [文档索引](../README.md)。

## 1. 版本要点

| 方向 | 内容 |
| --- | --- |
| 一键体检 | 固定七项顺序执行；正常 / 异常（错误码）/ 跳过（能力原因）/ 失败（建议）；总体结论、进度、取消、失败不中断、复制/保存 |
| 升级向导 | 五步：选择 → 预检逐条规则 → 确认 → 传输 → 结果；可回上一步/取消；断点「从 X% 继续」或失效原因 |

## 2. 关键规则

### 体检结论

- 正常：指令成功且判断项在阈值内；
- 异常：设备拒绝且非「能力不支持」，附带设备错误码 `0x..`；低电量与心跳电量差异也归为异常；
- 跳过：设备明确返回不支持，或本地没有可视键/参数/OTA 记录，附原因；
- 失败：超时或传输失败，附操作建议；单项失败继续执行后续项，链路断开才全局中止。

### 向导取消与断点

- 选择/预检/确认取消：丢弃当前选择并离开向导；
- 传输中取消：等同中止，状态收敛为 `Aborted`，随后进入结果页；
- 结果页：可再次升级回到选择步骤；断点只在预检通过、固件一致且 CRC-16 匹配时可续传。

### 仪表盘采样

- 每次刷新记录一次电量与 RSSI；每设备最多 50 点，超出淘汰最旧；空值不写；
- 采样只存本机并标注「本机采样，非设备历史」，不上传；不足 3 点不画线。

## 3. 未验证项

- 体检在真实设备上的错误码与超时表现未验证；
- 向导在真机断连、系统杀后台时的断点续传行为未验证；
- Android 13+ 与 iOS 通知/权限未在真机验证（沿用 v2.5.0 边界）；
- iOS 完整 App 构建仅在本地验证，远程 runner 结论以 Actions 记录为准。
