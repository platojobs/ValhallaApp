# v3.1.0 - 细节收口

- 版本：`3.1.0`（`versionCode 31`）
- 基线：v3.0.0（远端 `9d50a44`）
- 主题：只对 v3.0.0 承认的三处折扣收口，不新增业务方向

## 1. detekt 基线瘦身

- 基线由 **391 条降到 95 条**（净减 296 条），全部通过修改代码消除，
  未新增 `@Suppress`、未增加规则例外、未排除目录。
- 分模块：core 266 → 30、data 10 → 5、feature 115 → 60、composeApp 0 → 0。
- 按规则的真实净减：

| 规则 | v3.0.0 | v3.1.0 | 净减 |
|---|---:|---:|---:|
| MagicNumber | 260 | 0 | -260 |
| MaxLineLength | 18 | 0 | -18 |
| ComplexCondition | 6 | 0 | -6 |
| UnusedParameter | 3 | 0 | -3 |
| MatchingDeclarationName | 2 | 0 | -2 |
| CyclomaticComplexMethod | 20 | 18 | -2 |
| LongParameterList | 6 | 4 | -2 |
| InstanceOfCheckForException | 1 | 0 | -1 |
| LongMethod | 17 | 16 | -1 |
| SwallowedException | 3 | 2 | -1 |
| **合计** | **391** | **95** | **-296** |

- 主要处理方式：
  - 魔法数字全部提取为具名常量（协议码、位掩码、偏移、时间单位、校验边界），
    同值不同义不合并；
  - 长参数表改参数 `data class`（`DeviceDashboardCardUi`、`AutomationRuleRowUi`）；
  - 复杂函数拆分（`DeviceDashboardTrend`、`ConfigCapabilityNotice`、`QuickActionResult`、
    `BackupPreview`、`BatchDeviceOption` 独立文件）；
  - 复杂条件抽具名布尔中间量；
  - 空块、冗余分支、未使用参数与静默异常一并清理
    （`CommandFailure.InvalidResponse` 现在携带 `cause`）。
- 剩余 95 条逐条理由见 [static-analysis-baseline.md](../static-analysis-baseline.md)：
  协议解析的状态机分支、需要保留字段级异常定位的 `ThrowsCount`、Compose 渲染函数的
  天然长参数表、平台边界必须捕获 `Throwable` 等；每条均说明「为什么拆不掉或不应拆」，
  没有「历史遗留」这类理由。

## 2. UI 业务逻辑下沉与覆盖率

- 新增 [UiLogic.kt](../../feature/src/commonMain/kotlin/com/valhalla/feature/uilogic/UiLogic.kt)，
  把 Compose 里的纯逻辑迁出为普通函数/类：RSSI 分档文案、运行时长、状态与结果文案映射、
  配置字段状态与可执行动作、参数/快捷操作按钮启停、可编辑字段过滤、命令类型列表、
  时间线/参数类型文案等。
- 新增 [UiLogicTest.kt](../../feature/src/jvmTest/kotlin/com/valhalla/feature/uilogic/UiLogicTest.kt)
  29 项测试；新增 [UiAccessibilitySourceTest.kt](../../feature/src/jvmTest/kotlin/com/valhalla/feature/ui/UiAccessibilitySourceTest.kt)
  5 项源码约束测试。feature 测试由 279 增至 313。
- 覆盖率排除范围从整个 `com.valhalla.feature.ui` 包收窄为
  `annotatedBy("androidx.compose.runtime.Composable")`：只排除真正的渲染函数，
  包内的普通类/函数仍计入覆盖率。
- feature 层行覆盖变化：

| 口径 | 覆盖行 / 总行 | 行覆盖率 |
|---|---:|---:|
| 整包排除 UI（v3.0.0） | 6547 / 7318 | 89.46% |
| 仅排除 `@Composable`（v3.1.0） | 6566 / 7742 | **84.81%** |

- 差值来源：排除口径收窄后新增计入 424 行非 `@Composable` UI 代码，其中新增测试覆盖 19 行、
  未覆盖 405 行（主要是布局辅助、状态分支与仅在平台环境执行的桥接代码）。
  分母变大导致比例下降，但计入口径更真实；模块阈值仍按 80% 硬校验并通过。
- 三模块实测：core 94.31%（5386/5711）、data 87.55%（408/466）、feature 84.81%（6566/7742）。

## 3. 界面四态一致性

- 新增 [ScreenState.kt](../../feature/src/commonMain/kotlin/com/valhalla/feature/ui/ScreenState.kt)：
  `EmptyStatePanel`、`LoadingStatePanel`、`ErrorStatePanel`、`DisabledStatePanel`。
- 逐屏核对 16 个界面：扫描、已连接设备、详情、配置、参数、预设、OTA、日志、导出、体检、
  诊断、自动化、统计、备份、设置、关于/帮助/隐私。
- 每屏的空态、加载态、错误态、禁用/不可用态实现位置见
  [ui-state-matrix.md](../ui-state-matrix.md)；确实不适用的（例如只读同步页面）已写明原因。
- 新增 11 个 `StringKey`（空/加载/错误/禁用标题与原因、未连接/只读/忙碌/环境不支持），
  中英文在 `Strings.kt` 同表同步，无硬编码中文。
- 四态组件统一处理读屏语义：
  - 加载条声明 `progressBarRangeInfo` 与 `contentDescription`；
  - 错误与操作结果使用 `liveRegion`（错误为 Assertive，普通结果与空态为 Polite）；
  - 禁用态直接朗读不可用原因。

## 4. 无障碍与排版

- 可点击卡片、列表项、按钮、长按复制项补齐 `contentDescription` 或合并语义。
- 所有进度类组件（详情加载、体检、预检、OTA 传输、日志导出、诊断报告/打包、批量与队列）
  均声明 `progressBarRangeInfo`。
- 错误与结果文本统一加 `liveRegion`；保存/分享/复制等结果均有可朗读反馈。
- 弹窗统一使用 `AlertDialog` 并实现 `onDismissRequest`，返回键可关闭。
- 关键信息文本不使用 `maxLines` 截断；长内容依赖滚动容器，200% 字体下保持可读。
- 新增源码扫描测试约束：RTL 场景下 UI 不使用绝对左右布局、进度语义存在、
  对话框可返回、关键文本无截断。
- 对比度测试覆盖 `success / warning / error / inProgress` 在亮色与暗色主题下均达到
  WCAG AA 4.5:1；本轮四态组件复用既有状态色，未新增状态色。
