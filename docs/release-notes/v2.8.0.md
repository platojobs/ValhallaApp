# v2.8.0 - 实时信号、本地通知与诊断包

## 实时信号与连接质量

- 连接期间按配置周期（1–10 秒，默认 3 秒）读取真实 RSSI：Android 使用
  `BluetoothGatt.readRemoteRssi()` + `onReadRemoteRssi`，iOS 使用
  `CBPeripheral.readRSSI()` + `didReadRSSI`，与其它 GATT 操作共用串行锁。
- 订阅默认开启，可在设置中关闭并调整周期；断开自动停止，重连自动恢复。
- 连续 3 次读取失败或平台不支持时降级为扫描快照，并在仪表盘标注「连接实时」/「扫描快照」
  与降级原因，不阻断连接主流程。
- 实时样本写入既有 `DeviceMetricRepository`（每设备 50 点环形上限）；旧版本采样格式按空
  数据处理并在界面说明，新样本继续按 `v1` 追加。

## 本地通知（仅 App 存活期间）

- 事件：OTA 完成 / OTA 失败 / 自动重连耗尽 / 体检异常；点击通知直达对应设备页。
- Android 13+ 请求 `POST_NOTIFICATIONS`，拒绝后降级为应用内横幅且不再反复弹窗；
  iOS 请求 `UNUserNotificationCenter` 授权，拒绝同样降级。
- 通知总开关与事件渠道开关可分别关闭；同一事件按「类型 + 设备 + 内容」去重（10 分钟窗口），
  页面在前台可见时可按配置跳过。
- 边界：只在 App 存活期间送出，不承诺进程被杀后提醒；不新增后台任务或远程推送。

## 诊断包（一键留证）

- 从诊断页生成单个 `.vhdiag` 容器，包含：`manifest.json`、体检报告、连接质量统计、最近报文
  日志（脱敏）、设备档案摘要、版本与构建信息、指标采样；复用既有保存/分享通道。
- `manifest.json` 含 `schemaVersion`、生成时间、条目清单（名称/字节/条数）、`redacted`、`truncated`。
- 明确排除令牌、密钥、凭据、断点文件、固件二进制与未脱敏原文；所有自由文本写入前再次脱敏。
- 生成有进度、可取消；完成前不触碰文件系统，失败或取消不留半成品。报文超出既有导出上限时
  截断并在 manifest 标注 `truncated`。

## 测试与边界

- 新增 RSSI 订阅启停/降级、旧采样格式兼容、通知去重与权限降级、诊断包字段白名单、
  manifest 结构、超限截断与取消不留结果等测试。
- 不支持后台常驻或远程推送，诊断包含任何敏感项均视为缺陷。
