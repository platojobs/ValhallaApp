## 2. 能力边界与关键决策

### 固件库

- 只保存元信息与平台文件引用，**不复制固件二进制**：固件体积大，复制会放大备份与清理成本；
  文件仍由系统选择器持有。
- 复用前重新打开原始引用并重算 payload CRC-32，结果分「可用 / 文件不可访问 / 读取失败 /
  CRC 不一致 / 未找到」，均给出可操作提示，不假装可用。
- 身份由 `CRC-32 + payload 总长 + 版本` 组成，同一固件从不同路径重新选择会归并为一条；
  默认保留 20 条，淘汰顺序为「非常用优先、最久未用优先」。

### 诊断报告

- 只使用本机真实快照：会话状态、设备档案、本机报文日志；缺失项写「暂无数据」，不做估算。
- 生成前用与生成完全相同的渲染逻辑计算小节与体积，避免预览与结果不一致。
- 所有自由文本经 `SensitiveTextRedaction`，设备 ID 只输出不可逆短哈希；报文逐条经
  `formatForCopy` 后再次脱敏。
- 生成是 suspend 的，逐小节检查取消；取消不返回部分结果。

### 事件时间线

- 存储层每次读取都走平台键值，跨进程可读；写入异常被吞掉并返回 false，不影响连接/OTA。
- 每设备独立存储，读取时按时间倒序，最多保留 100 条；落盘前对摘要/详情/错误码脱敏。

### 本地提醒

- 默认全部关闭；低电量要求「未充电且 ≤ 阈值」，用滞回 5 个百分点去抖，进入低电只提醒一次。
- Android 13+ 使用 `POST_NOTIFICATIONS` 与既有权限状态机；iOS 使用
  `UNUserNotificationCenter`；被拒绝后不重复弹窗，只展示权限状态与系统设置入口。
- 通知内容只在本机生成与展示，不进入任何上传通道。

## 3. 未验证项

- 固件库在 Android SAF 授权过期、iOS 文件被移动后的真实行为未验证；

- 时间线在多进程并发写入下的行为未验证（当前约定单进程使用）。
