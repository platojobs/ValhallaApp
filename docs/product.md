# 产品说明（v2.5.0）

面向使用者的功能与文案约定。技术细节见 [architecture.md](architecture.md)，存储清单见
[storage.md](storage.md)。

## 1. 功能一览

| 模块 | 能力 |
| --- | --- |
| 扫描 | BLE 扫描、去重、按名称/信号过滤、12 秒无结果提示、权限/蓝牙状态引导 |
| 连接 | 建立链路、并发命令调度、连接失败原因（超时 / 传输 / 设备拒绝）、自动重连退避 |
| 详情 | 设备信息、固件版本、电量、充电状态、设备档案（最近连接、OTA 历史）；顶部仪表盘展示电量/充电/固件/uptime/信号来源与最近 50 点本机采样折线；「设备体检」按固定七项顺序执行并给出正常/异常/跳过/失败结论，可复制与保存 |
| 固件升级向导 | 五步：选择文件与版本 → 预检逐条规则与阻断 → 升级前确认（版本对比/电量/勿断连/断点说明）→ 传输（阶段/进度/重传/中止）→ 结果（成功/失败原因/是否可续传）；每步可上一步或取消，断点入口显示「从 X% 继续」或失效原因 |
| 配置 | 按设备能力展示可编辑项、只读/不支持项隐藏并说明、保存结果提示 |
| 参数 | `GET_PARAM` / `SET_PARAM` 读写、本地类型/范围/字节长度校验、单在途、错误码；参数表标注「需固件确认」 |
| 诊断 | 仅基于本机报文日志的连接质量：成功率、平均/最大时延、重传、乱序、错误码分布、分命令明细；样本 < 20 条只提示样本不足；可生成 Markdown/纯文本诊断报告（含脱敏报文、预览体积、进度与取消） |
| 引导 | 三步首次使用引导（权限说明 / 扫描 / 连接与鉴权），可跳过、不自动弹权限框、设置页可重看 |
| OTA | 固件预检、分片传输、进度/速率/剩余时间、失败原因、断点续传与手动清除断点；本地固件库（版本/渠道/型号/CRC/最近使用，复用前重开文件校验） |
| 时间线 | 详情页活动时间线：连接/断开、鉴权、配置/参数变更、OTA 阶段与错误；倒序、类型筛选、每设备最近 100 条 |
| 提醒 | 可选本地通知：OTA 完成/失败、断连、低电量（默认 20%，可配 5..50）；默认全部关闭，拒绝权限后静默降级 |
| 日志 | 内存报文日志（默认 500 条，可在设置中调到 100..1000）、命令/错误/时间/关键字筛选、复制单条 |
| 导出 | JSON/CSV 流式导出、条目与字节预算、保存文件或系统分享；默认预算可在设置页预设 |
| 设置 | 语言（中文 / English / 跟随系统）、主题、重连次数 1..5、退避上限 5..60 秒、日志容量、导出默认值、本地提醒开关与低电量阈值 |
| 关于 | 应用名、版本号与构建号、构建渠道、平台、提交号（取不到显示「未知」）、逐条依赖许可 |
| 帮助 | 蓝牙权限、连接失败、OTA 失败、日志位置、参数面板、连接质量、引导、本地提醒七类常见问题 |
| 隐私 | 本机存储清单（位置/key/是否持久化）、无网络上传声明、清除方式 |

## 2. 语言与主题

- 语言默认跟随系统：系统为 `zh*` 时中文，其余英文；可在「设置」中强制中文或 English，
  切换后当前页面立即刷新（文案、按钮、错误提示同步变化）。
- 日期时间使用同一套格式化：列表显示相对时间（刚刚 / n 分钟前），详情与导出显示绝对时间，
  两者由系统时区与语言共同决定；英文数字带千位分隔，中文保留原始数字。
- 主题默认跟随系统深浅色，也可手动锁定浅色/深色；强调色、圆角、间距与状态色来自统一
  设计令牌，不随页面变化。

## 3. 文案规范

- **错误提示**统一为「现象 + 原因 + 可操作建议」，例如：
  「读取固件失败：{偏移}。请确认文件仍可访问后重新选择。」
- 可本地化的原因通过 `UiMessage` 嵌套渲染；设备状态码、文件解析结果等协议细节作为
  **技术详情**原样展示（多为英文/十六进制），不伪装成已翻译文案。
- **空态**区分：无权限、蓝牙关闭/重置、不支持、扫描中、扫描超时、无设备、扫描失败；
  每种都有独立动作按钮或说明，不会一律显示「暂无设备」。
- **加载态**：读取设备信息、读取配置、导出准备分别有明确文案；**进行中**：扫描显示时长与
  取消，OTA 显示阶段、进度、速率与剩余时间，导出显示阶段与已处理条数。
- 失败/成功/警告/进行中的文字颜色统一取 `statusColors()`（成功绿、警告橙、失败红、
  进行中蓝），亮暗主题各一套。

## 4. 关于、帮助与隐私

- **关于**：应用名 `Valhalla`、版本 `2.5.0 (25)`（构建期从 `gradle.properties` 生成，
  与 Android/iOS 同源）、构建渠道、当前平台、提交号（构建时取自
  `VALHALLA_BUILD_COMMIT` / `GITHUB_SHA` / git，取不到显示「未知」）、依赖许可逐条列出
  （名称、版本、许可证、作用域）。
- **帮助**（只写已实现行为）：
  - 蓝牙权限：首次连接时申请；拒绝后再次点击会重新申请；永久拒绝需去系统设置开启；
  - 连接失败：确认设备在附近、未连接其他手机、电量充足；自动重连次数与退避上限可在设置中调整；
  - OTA 失败：检查固件匹配与电量；支持续传，也可在升级页清除断点后从头升级；
  - 日志位置：仅内存（默认 500 条，可调 100..1000），退出即清空；在「报文日志」中保存文件或系统分享；
  - 参数面板：本地校验后才下发，参数表为协议约定值且标注「需固件确认」；
  - 连接质量：只用本机报文日志，样本不足只提示数量；诊断报告只读本机快照，可预览体积并取消；
  - 固件库：只记元信息与文件引用，复用前重新打开并校验 CRC，失效时提示重选；
  - 本地提醒：默认关闭，按 OTA/断连/低电量逐项开启；权限被拒后不重复弹窗；
  - 引导：可跳过、完成状态本地保存、不会自动弹系统权限框。
- **隐私**：按当前平台列出设备档案、OTA 断点、鉴权令牌、报文日志、固件库、事件时间线、应用偏好、
  蓝牙权限标记的存储位置与 key；报文日志不落盘；固件库不缓存固件二进制；应用未声明 `INTERNET`
  权限，**当前版本没有任何网络上传**。
  Android 卸载/清除数据即删除；iOS 删除 App 后 Keychain 由系统管理。

## 5. 验收边界

自动化（JVM 宿主）覆盖：文案 key 完整性与占位符、英文无中文、界面无硬编码中文、
语言解析、主题解析、偏好读写与回退、隐私清单与存储键一致、版本号同源、ECDSA 验签、
远端上报脱敏、状态色对比度、公钥注入优先级、跨端运行时验签、多设备/扫描/快捷操作逻辑、
参数表校验与单在途、连接质量统计口径、固件库归并与淘汰、事件时间线环形与脱敏、
诊断报告章节与体积预估、通知开关与低电去抖、引导与偏好读写，
JVM 合计 579 项测试，
另含 Android instrumented 7 项与 iOS 模拟器运行时 339 项用例。

需要人工/真机确认（本文不声称已验证）：

- 系统语言切换与深色模式在 Android/iOS 上的实际渲染、字体与断行；
- 设置页切换语言/主题后的整页刷新效果与动画；
- 权限弹窗、去系统设置、蓝牙开关等系统交互与首次引导在真机上的表现；
- 参数面板在真实固件上的读写结果（参数表本身仍需固件确认）；
- 连接质量看板在真机长会话下的统计与滚动性能；
- 关于/帮助/隐私页在小屏与横屏下的排版；
- 本地通知在真机上的展示、权限弹窗与系统设置跳转；通知只在本机生成，不上传；
- 固件库在 SAF 授权过期、iOS 文件被移动后的真实复用行为；
- 设备事件时间线在多进程并发写入下的表现（当前约定单进程使用）；
- 真机上的状态色对比度与可访问性。
