# 产品说明（v2.2.0）

面向使用者的功能与文案约定。技术细节见 [architecture.md](architecture.md)，存储清单见
[storage.md](storage.md)。

## 1. 功能一览

| 模块 | 能力 |
| --- | --- |
| 扫描 | BLE 扫描、去重、按名称/信号过滤、12 秒无结果提示、权限/蓝牙状态引导 |
| 连接 | 建立链路、并发命令调度、连接失败原因（超时 / 传输 / 设备拒绝）、自动重连退避 |
| 详情 | 设备信息、固件版本、电量、充电状态、设备档案（最近连接、OTA 历史） |
| 配置 | 按设备能力展示可编辑项、只读/不支持项隐藏并说明、保存结果提示 |
| OTA | 固件预检、分片传输、进度/速率/剩余时间、失败原因、断点续传与手动清除断点 |
| 日志 | 内存报文日志（默认 500 条）、命令/错误/时间/关键字筛选、复制单条 |
| 导出 | JSON/CSV 流式导出、条目与字节预算、保存文件或系统分享 |
| 设置 | 语言（中文 / English / 跟随系统）、主题（跟随系统 / 浅色 / 深色） |
| 关于 | 应用名、版本号与构建号、构建渠道、平台、开源许可 |
| 帮助 | 蓝牙权限、连接失败、OTA 失败、日志位置四类常见问题 |
| 隐私 | 本机存储清单（位置/key/是否持久化）、无网络上传声明、清除方式 |

## 2. 语言与主题

- 语言默认跟随系统：系统为 `zh*` 时中文，其余英文；可在「设置」中强制中文或 English，
  切换后当前页面立即刷新（文案、按钮、错误提示同步变化）。
- 日期时间使用同一套格式化：列表显示相对时间（刚刚 / n 分钟前），详情与导出显示绝对时间，
  两者由系统时区与语言共同决定；英文数字带千位分隔，中文保留原始数字。
- 主题默认跟随系统深浅色，也可手动锁定浅色/深色；强调色、圆角、间距与状态色来自统一
  设计令牌，不随页面变化。

## 3. 文案规范

- **错误提示**统一为「现象 + 原因 + 可操作建议」，例如：
  「读取固件失败：{偏移}。请确认文件仍可访问后重新选择。」
- 可本地化的原因通过 `UiMessage` 嵌套渲染；设备状态码、文件解析结果等协议细节作为
  **技术详情**原样展示（多为英文/十六进制），不伪装成已翻译文案。
- **空态**区分：无权限、蓝牙关闭/重置、不支持、扫描中、扫描超时、无设备、扫描失败；
  每种都有独立动作按钮或说明，不会一律显示「暂无设备」。
- **加载态**：读取设备信息、读取配置、导出准备分别有明确文案；**进行中**：扫描显示时长与
  取消，OTA 显示阶段、进度、速率与剩余时间，导出显示阶段与已处理条数。
- 失败/成功/警告/进行中的文字颜色统一取 `statusColors()`（成功绿、警告橙、失败红、
  进行中蓝），亮暗主题各一套。

## 4. 关于、帮助与隐私

- **关于**：应用名 `Valhalla`、版本 `2.2.0 (22)`（构建期从 `gradle.properties` 生成，
  与 Android/iOS 同源）、构建渠道 `stable`、当前平台、开源许可说明。
- **帮助**（只写已实现行为）：
  - 蓝牙权限：首次连接时申请；拒绝后再次点击会重新申请；永久拒绝需去系统设置开启；
  - 连接失败：确认设备在附近、未连接其他手机、电量充足；自动重连最多 5 次后停止；
  - OTA 失败：检查固件匹配与电量；支持续传，也可在升级页清除断点后从头升级；
  - 日志位置：仅内存（默认 500 条），退出即清空；在「报文日志」中保存文件或系统分享。
- **隐私**：按当前平台列出设备档案、OTA 断点、鉴权令牌、报文日志、应用偏好、蓝牙权限标记
  的存储位置与 key；报文日志不落盘；应用未声明 `INTERNET` 权限，**当前版本没有任何网络上传**。
  Android 卸载/清除数据即删除；iOS 删除 App 后 Keychain 由系统管理。

## 5. 验收边界

自动化（JVM 宿主）覆盖：文案 key 完整性与占位符、英文无中文、界面无硬编码中文、
语言解析、主题解析、偏好读写与回退、隐私清单与存储键一致、版本号同源、ECDSA 验签、
远端上报脱敏、状态色对比度、公钥注入优先级与跨端运行时验签，JVM 合计 501 项测试，
另含 Android instrumented 7 项与 iOS 模拟器 6 项 ECDSA 运行时用例。

需要人工/真机确认（本文不声称已验证）：

- 系统语言切换与深色模式在 Android/iOS 上的实际渲染、字体与断行；
- 设置页切换语言/主题后的整页刷新效果与动画；
- 权限弹窗、去系统设置、蓝牙开关等系统交互；
- 关于/帮助/隐私页在小屏与横屏下的排版；
- 真机上的状态色对比度与可访问性。
